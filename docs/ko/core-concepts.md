# 핵심 개념

이 페이지는 문서 전반에서 반복적으로 언급되는 기초 개념을 모아 둔 곳입니다. 필요한 개념이 늘어날 때마다 이 페이지에 섹션이 추가됩니다.

## 라운드란 무엇인가요?

> [!NOTE]
> **라운드(Round)** 는 앱이 모델을 한 번 호출해 응답을 받는 **한 번의 왕복**입니다. 앱이 프롬프트를 보내고 모델이 답하면 그게 1라운드입니다. 일반 채팅은 1라운드로 끝나지만, function calling이나 agent는 사용자 메시지 하나에 여러 라운드가 이어질 수 있습니다.

### 가장 단순한 경우: 1라운드로 끝나는 대화

일반 채팅 메시지에서는 모델이 한 번의 호출로 답을 완성합니다.

```
앱  →  "2 더하기 2는?"          →  모델
앱  ←  "4입니다."                ←  모델
```

이 경우 `RoundUsage`는 이 한 번의 호출에서 쓴 토큰을 담고, 스트림이 끝날 때 `Completion.Usage`에도 같은 값(1라운드만의 합계)이 담깁니다.

### 여러 라운드가 발생하는 경우: Function Calling

모델이 혼자 답할 수 없을 때 라운드가 늘어납니다. 사용자가 *"지금 서울 날씨 알려줘"* 라고 물었다고 해봅시다. 모델은 실시간 날씨를 알 방법이 없으므로 도구(함수)를 호출하려 합니다.

**1라운드 — 모델이 도구 호출을 결정**

앱은 사용자 메시지와 등록된 도구 목록(예: `GetWeather`)을 모델에 전달합니다. 이 시점에 모델이 보는 대화는 다음과 같습니다.

```
system: 너는 날씨 assistant야. GetWeather(city)를 호출할 수 있어.
user:   지금 서울 날씨 알려줘
```

모델은 최종 답변을 쓰는 대신 **도구 호출 요청**을 반환합니다.

```
tool_call: GetWeather(city="Seoul")
```

모델의 턴이 끝나면서 1라운드도 끝납니다. 이 시점에 `RoundUsage`가 발생하며 1라운드에서 쓴 토큰이 담깁니다. **사용자에게 보여줄 답변은 아직 없습니다.**

**라운드 사이 — 앱이 함수를 직접 실행**

이 구간은 **LLM 호출이 아닙니다.** Mythosia.AI 런타임이 여러분이 등록한 `GetWeather` 함수를 직접 호출하고, 결과 `"15°C, 흐림"`을 받아옵니다. 토큰 소비는 없습니다.

**2라운드 — 모델이 결과를 보고 최종 답변 작성**

앱은 이제 도구 결과를 대화에 추가해 모델을 **한 번 더** 호출합니다. 모델이 보는 대화는 이렇게 됩니다.

```
system:      너는 날씨 assistant야. GetWeather(city)를 호출할 수 있어.
user:        지금 서울 날씨 알려줘
assistant:   [GetWeather(city="Seoul")를 호출함]
tool_result: 15°C, 흐림
```

필요한 정보를 모두 갖춘 모델은 이번엔 텍스트로 답변합니다.

```
현재 서울은 15°C이고 흐립니다.
```

2라운드가 끝납니다. `RoundUsage`가 한 번 더 발생하며 이번엔 2라운드의 토큰만 담깁니다(대화가 길어졌으므로 보통 1라운드보다 input 토큰이 많습니다). 스트림이 종료되면 `Completion.Usage`가 발생하며 여기엔 **1라운드 + 2라운드의 합계**가 담깁니다.

### 한눈에 보기

| 단계 | LLM 호출? | 무슨 일이 일어나는가 | 발생 이벤트 |
|---|---|---|---|
| 1라운드 | ✅ | 모델이 `GetWeather` 호출을 결정 | `RoundUsage` (`RoundIndex=1`) |
| 라운드 사이 | ❌ | 앱이 함수 실행 → `"15°C, 흐림"` 수신 | `FunctionCall`, `FunctionResult` |
| 2라운드 | ✅ | 모델이 결과를 보고 최종 답변 작성 | `RoundUsage` (`RoundIndex=2`, `IsFinalRound=true`) |
| 스트림 종료 | — | — | `Completion` (Usage = 1라운드 + 2라운드) |

### 도구를 여러 번 호출하면 라운드가 더 늘어납니다

모델이 연속해서 여러 도구를 호출해야 한다면 라운드도 늘어납니다. 예를 들어 *"서울과 도쿄 날씨를 비교해줘"*라면 다음과 같이 진행됩니다.

1. **1라운드** — 모델이 `GetWeather("Seoul")` 호출
2. 앱이 실행 → `"15°C, 흐림"`
3. **2라운드** — 모델이 결과를 보고 이어서 `GetWeather("Tokyo")` 호출
4. 앱이 실행 → `"18°C, 맑음"`
5. **3라운드** — 모델이 두 결과를 종합해 최종 답변 작성

총 3라운드이고, `Completion.Usage`는 세 라운드 토큰의 합입니다. UI 컨텍스트 미터는 마지막 라운드인 3라운드의 `RoundUsage.TotalTokens`를 쓰면 됩니다.
